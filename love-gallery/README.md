# love-gallery

Отдельная галерея для `love-timer`.

## Что уже готово

- отдельная страница `index.html`;
- тот же тёмный кинематографичный стиль;
- плавное появление карточек;
- `loading="lazy"` для фотографий после первого кадра;
- `decoding="async"`;
- полноэкранный просмотр без библиотеки;
- закрытие через Esc и клик по затемнению;
- переключение стрелками и свайпом на телефоне;
- предварительная загрузка только соседних полноразмерных кадров;
- `prefers-reduced-motion`;
- без предварительного `Promise.all`/проверки каждого файла: это важно, потому что массовая проверка картинок сама скачивала бы их и ломала идею lazy-loading.

## Быстрый запуск

Создай публичный репозиторий `love-gallery`.

Загрузи в него:

```text
love-gallery/
├─ index.html
└─ photos/
   ├─ thumbs/
   └─ full/
```

Потом открой GitHub → репозиторий → **Settings → Pages** → **Build and deployment** → **Deploy from a branch** → `main` → `/(root)` → **Save**.

Адрес будет:

`https://isqueez.github.io/love-gallery/`

Главная страница `love-timer` уже содержит карточку «Открыть галерею» с этим адресом.

## Как добавлять фотографии

Лучший вариант — две версии каждого снимка.

```text
photos/thumbs/02.webp   ← небольшое превью для сетки
photos/full/02.webp    ← крупная версия для просмотра
```

После этого добавь объект в `GALLERY_ITEMS` внутри `index.html`:

```js
{
  preview: 'photos/thumbs/02.webp',
  full: 'photos/full/02.webp',
  title: 'Ещё один момент',
  meta: '2026',
  alt: 'Наша фотография'
}
```

Для большого альбома не клади исходники с телефона по 5–15 МБ прямо в сетку. Для превью лучше держать изображение примерно в размерах, которые реально нужны карточке, а полноразмерные кадры уменьшить до разумного максимального размера длинной стороны.

## Первый кадр

Сейчас единственная готовая запись использует:

`https://isqueez.github.io/love-timer/photo1.jpg`

Так галерею можно открыть сразу после публикации, даже если ты ещё не скопировал фотографии в новый репозиторий.

Когда захочешь полностью отделить медиа от `love-timer`, замени этот URL на локальные пути из `photos/`.
